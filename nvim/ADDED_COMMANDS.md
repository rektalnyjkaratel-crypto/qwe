# Added Commands

Короткая подсказка по последним добавлениям для навигации, Rust, фронта и git.

| Клавиши | Что делает |
| --- | --- |
| `Пробел cL` | Показать LSP-клиенты текущего буфера |
| `Пробел cF` | Показать formatter'ы текущего буфера |
| `]m` | Следующая функция или метод |
| `[m` | Предыдущая функция или метод |
| `]T` | Следующий тип: struct, enum, trait, interface и похожие объявления |
| `[T` | Предыдущий тип: struct, enum, trait, interface и похожие объявления |
| `Пробел ch` | Включить или выключить LSP inlay hints в текущем буфере |
| `Пробел ca` в visual mode | Показать LSP code actions для выделенного кода |
| `Пробел Re` | Вынести выделенный код в функцию |
| `Пробел RE` | Вынести выделенный код в функцию в отдельном файле |
| `Пробел Rv` | Вынести выделенное выражение в переменную |
| `Пробел Ri` | Встроить переменную под курсором |
| `Пробел RI` | Встроить функцию под курсором |
| `Пробел Rs` | Выбрать рефакторинг из меню |
| `Пробел rr`, `rc`, `rb`, `rl`, `rt` | Rust: cargo run/check/build/clippy/test |
| `Пробел Gp`, `Gt`, `Gb`, `Gv` | Go: test package, test all, build all, vet all |
| `]h` | Следующее git-изменение в файле |
| `[h` | Предыдущее git-изменение в файле |
| `Пробел gp` | Показать git hunk |
| `Пробел gs` | Stage текущий git hunk |
| `Пробел gr` | Откатить текущий git hunk |
| `Пробел gb` | Git blame текущей строки |

## Notes

Treesitter включается сам при открытии файла и даёт более точную подсветку для
Go, Rust, Svelte, TS, HTML, CSS и остальных настроенных языков.

Rust использует `rust-analyzer` для переходов, подсказок и диагностики. При
сохранении `.rs` запускается форматирование через LSP, обычно это `rustfmt` из
установленного Rust toolchain.

Rust/Go команды открывают нижний терминал в корне проекта и сначала сохраняют
текущий файл.

Autopairs включается при входе в insert mode и автоматически закрывает скобки
и кавычки. `Enter` не перехватывается, чтобы не конфликтовать с blink.cmp.

Gitsigns включается только внутри git-репозитория. В новых проектах сначала нужен
обычный `git init`.

`Пробел R...` использует refactoring.nvim. Для создания отсутствующей функции,
метода, импорта или реализации сначала поставь курсор на диагностику и используй
обычное LSP-меню `Пробел ca`.
